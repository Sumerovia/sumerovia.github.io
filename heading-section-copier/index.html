Heading Section Copier

Copy the current section based on the document’s heading structure while preserving supported formatting.

What it does

Heading Section Copier identifies the section that contains the cursor or a selection by using Heading 1 through Heading 6 in the current document.

A section starts with its heading and includes its content and lower-level subheadings. It ends immediately before the next heading of the same level or a higher level.

How to use it

  1. Place the cursor inside a section, or make a selection that stays entirely within one section.
  2. Run Copy current section.
  3. Review the generated preview.
  4. Select Copy section.
  5. Paste the result into Google Docs or another application that accepts clipboard content.

If a selection crosses a section boundary, the add-on does not copy content based only on where the selection starts. Keep the cursor or selection within a single section and try again.

Supported formatting

The current implementation has been tested with the following content and formatting:

  • Headings and paragraphs
  • Bold, italic, underline, and strikethrough
  • Font family and size
  • Text color and background color
  • Links
  • Superscript and subscript
  • Alignment and text direction
  • Indentation
  • Bulleted and numbered lists, including nested levels
  • Tables
  • Inline images

The add-on also provides a text/plain representation as a fallback alongside formatted clipboard content.

Limitations

Heading Section Copier preserves supported content and formatting, but it does not guarantee an exact reproduction of every internal Google Docs property.

Some paragraph or heading properties, table data, and image or table dimensions may vary slightly after pasting. The final result also depends in part on how the receiving application handles clipboard content.

Features or element types that have not been explicitly tested are not described as supported.
