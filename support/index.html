Support

Get practical help with using Heading Section Copier.

How to use Heading Section Copier

  1. Open a Google Docs™ document organized with Heading 1 through Heading 6.
  2. Place the cursor inside the section you want to copy, or make a selection that stays entirely within one section.
  3. Run Copy current section.
  4. Review the preview.
  5. Select Copy section.
  6. Paste the result into the destination application.

Common situations

No section heading was found

This occurs when there is no Heading 1 through Heading 6 that governs the cursor position or selection.

No copyable content was found in this section

This occurs when a section heading is found but the section contains no material that can be copied.

Selection crosses a section boundary

This occurs when a selection extends into more than one section. Keep the selection within a single section, or place the cursor inside the section you want to copy.

Title and Subtitle styles are not treated as section headings. Use Heading 1 through Heading 6 to define sections.

Supported content

The current implementation has been tested with headings, paragraphs, common text formatting, links, indentation, text direction, bulleted and numbered lists including nested levels, tables, and inline images.

A text/plain representation is also provided as a fallback.

Known limitations

Heading Section Copier preserves supported content and formatting, but some internal Google Docs properties, table data, or image and table dimensions may differ slightly after pasting.

The final pasted result also depends in part on how the receiving application handles clipboard content. Features or element types that have not been explicitly tested are not described as supported.

Troubleshooting

  • Confirm that the document uses Heading 1 through Heading 6.
  • Make sure a selection does not cross into another section.
  • Try placing the cursor inside the section instead of using a selection.
  • Review the preview before copying.
  • Try pasting into Google Docs to check whether the issue is specific to the receiving application.
