Privacy Policy

This Privacy Policy explains how Heading Section Copier by Sumerovia handles document content and related data in the current implementation.

Effective date: September 19, 2026

Document access

Heading Section Copier accesses the content and structure of the current document only to the extent needed to perform the function requested by the user.

The material processed by the add-on may include headings, paragraphs, text, formatting, lists, tables, links, and inline images.

The add-on does not request general access to all of a user's Google Docs documents.

How document content is used

Document content accessed by the add-on is used only to:

  • Identify the section containing the cursor or selection.
  • Determine the section boundaries from the heading structure.
  • Generate the preview.
  • Prepare text/html and text/plain representations for copying to the clipboard.

Document content is not used for advertising, user profiling, or purposes unrelated to the product's functionality.

Storage and external transmission

In the current implementation, Sumerovia does not operate an external server or database that stores document content for Heading Section Copier.

The current implementation does not intentionally retain document content for later use after the requested operation has been performed.

Document content may be processed temporarily by Google Apps Script, Google Docs, and browser clipboard mechanisms as needed to provide the add-on's functionality.

Heading Section Copier does not sell document content or personal information.

The current implementation does not send document content to Sumerovia-operated servers or to external parties for analytics, advertising, profiling, or other purposes unrelated to the product's functionality.

Google services

Data processing performed by Google as necessary to provide Google Docs, Google Apps Script, authorization, and related services is governed by Google's applicable terms and privacy policies.

Analytics, advertising, and tracking

The current implementation does not include analytics, advertising tools, or user-tracking functionality.

If this changes in the future, this Privacy Policy will be updated before new functionality that affects user data is used.

Permissions

The current implementation uses the following Google OAuth scopes:

  • https://www.googleapis.com/auth/documents.currentonly
  • https://www.googleapis.com/auth/script.container.ui

documents.currentonly limits document access to the current document in which the add-on is being used.

script.container.ui allows the add-on to display and interact with its user interface inside Google Docs.

Google API data use

Use of information received from Google APIs is limited to providing or improving the user-facing functionality described in this Privacy Policy and is subject to the applicable Google API Services User Data Policy, including the Limited Use requirements.

Stopping use and revoking access

You can stop using Heading Section Copier by uninstalling or disabling the add-on. You can also revoke authorization previously granted to the add-on through your Google Account settings.

Because the current implementation does not keep an externally stored copy of document content in a Sumerovia database, there is no external document-content database from which that material needs to be deleted when you stop using the add-on.
